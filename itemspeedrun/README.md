# Item Speedrun (Fabric, Minecraft 26.3)

Спидран добычи случайного предмета.

## Как играть

Напиши в чат `/itemrun`:

- в чате появится название случайного предмета, который можно добыть в выживании;
- вверху по центру экрана запустится секундомер;
- как только предмет окажется в инвентаре (хотбар, основной инвентарь, броня, вторая рука), секундомер остановится и в чат придёт итоговое время.

Команды (права оператора не нужны, поэтому работает в хардкоре и без читов):

| Команда | Что делает |
|---|---|
| `/itemrun` или `/itemrun start` | начать забег |
| `/itemrun reroll` | сменить предмет и перезапустить секундомер |
| `/itemrun cancel` | отменить забег |

Забег прерывается, если ты умер или вышел из мира. Предмет, который уже лежит у тебя в инвентаре, не выпадает.

Мод нужен и на клиенте (секундомер), и на сервере/в одиночной игре (выбор предмета и проверка инвентаря).

## Чёрный список

В игре нет флага «добывается в выживании», поэтому предметы только для креатива исключены списком в коде.
Если попался предмет, который добыть нельзя (например, из новой версии), добавь его id в
`config/itemspeedrun-blacklist.txt` (по одному в строке, например `minecraft:sponge`). Файл создаётся при первом запуске команды.

## Сборка

Нужны JDK 25 и Gradle 9.5+.

```
gradle wrapper --gradle-version 9.5.1
./gradlew build
```

Готовый мод: `build/libs/itemspeedrun-1.0.0.jar`. Для запуска нужны Fabric Loader 0.19.5+ и Fabric API для 26.3.

Если Gradle не находит `loom_version`, возьми актуальные значения `loader_version`, `loom_version`
и `fabric_version` из официального шаблона https://github.com/FabricMC/fabric-example-mod (ветка под 26.x)
и подставь в `gradle.properties`.
